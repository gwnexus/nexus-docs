# Platform and User Settings

Administration of tenants and platform configuration, plus per-user profile management. {{ className: 'lead' }}

Introduced in v0.12.0, the settings surfaces let administrators manage the tenant and platform configuration, and let users manage their own profile.

## Tenant management

Administrators can edit the tenant identity.

- **Name** — the tenant display name
- **Slug** — the tenant slug used in routing and references

## Platform settings

Platform configuration is organized into a tabbed settings interface under **Dashboard > System > Settings**, grouping related administrative options under a single page. Since v0.15.0, each section shows its title and description in a header band with a section selector beside it.

| Section | Since | Purpose |
| --- | --- | --- |
| Workspace Profiles | v0.15.0 | Claude Code workspace presets and the system default preset; see [Claude Code Workspace](/claude-code/workspace#managing-presets). The former "Claude Code Workspace" sidebar entry redirects here. |

**Platform > Directives** (v0.16.0) holds the platform directive catalog: rule texts written once for all projects, with usage and version per rule. See [Directives](/directives#platform-catalog).

## User profiles

Users can manage their own account.

- **Editable profile** — update personal profile fields
- **Password change** — available for email-authenticated accounts

<Note>
  Password change applies to email-auth accounts. Accounts authenticated through an external identity provider manage credentials with that provider.
</Note>

### My Settings > Workspace Profiles

Since v0.15.0, every user chooses a Claude Code workspace preset, switches panels and tabs, sets sizes and personal Zellij settings here. See [Claude Code Workspace](/claude-code/workspace#personal-settings).

## Landing page navigation

The landing-page selector uses a tree picker, letting users choose which page they land on after login from a hierarchical navigation view.
